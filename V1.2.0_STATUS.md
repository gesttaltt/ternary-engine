## Known Issues and Limitations

### Critical Issues
None currently blocking production use.

### Important Limitations

1. **Canonical Indexing Not Enabled**
   - **Status:** Deferred to v1.3.0
   - **Reason:** LUTs organized for `(a<<2)|b`, need reorganization for `(a*3)+b`
   - **Workaround:** AVX2_v2 uses traditional indexing
   - **Impact:** Missing 12-18% expected performance gain

2. **AVX2_v2 Slower for Large Arrays**
   - **Status:** Under investigation
   - **Observation:** AVX2_v2 slower than AVX2_v1 for 1M+ elements
   - **Suspected Cause:** Memory bandwidth or cache behavior
   - **Impact:** AVX2_v1 recommended for large arrays

3. **Fusion Operations Not Exposed**
   - **Status:** Validated but not in backend API
   - **Implementation:** Exists in `ternary_fusion.h`
   - **Performance:** 1.5-11× speedup validated
   - **Plan:** Add to backend interface in v1.3.0

4. **Dual-Shuffle Not Integrated**
   - **Status:** Implemented but not used
   - **Expected Gain:** 1.2-1.7× additional speedup
   - **Plan:** Integrate in v1.3.0

5. **LUT-256B Not Integrated**
   - **Status:** Implemented but not used
   - **Expected Gain:** +10-20% throughput
   - **Plan:** Integrate in v1.3.0

### Minor Issues

6. **OpenMP Disabled**
   - **Status:** Fixed but not re-enabled
   - **History:** CI crashes on OpenMP tests
   - **Root Cause:** Fixed (OMP_NUM_THREADS handling)
   - **Plan:** Re-enable after CI validation

7. **Linux/macOS Untested**
   - **Status:** Build scripts exist but not validated
   - **Blocker:** No CI for Linux/macOS
   - **Workaround:** Manual testing required
   - **Plan:** Validate in v1.3.0

8. **No Multi-Dimensional Arrays**
   - **Status:** Current implementation 1D only
   - **Workaround:** Flatten multi-dimensional arrays
   - **Plan:** Add in v2.0.0
